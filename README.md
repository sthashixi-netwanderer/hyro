# Hyro Music

![Hyro Music Preview](resources/preview.png)

A desktop music streaming app built with Electron, React, and Tailwind CSS.

## Download

Get the latest release from the [Releases page](https://github.com/sthashixi-netwanderer/hyro/releases).

## Development

```bash
npm install
npm run dev
```
